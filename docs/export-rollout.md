### Implementation Guidelines

1. **Shared Utility**  
   Use `lib/exportUtils.ts` for consistent file naming, column autofit, and summary tabs.

2. **Per-Screen Insight Blocks**  
   Each export should begin with a “Summary” sheet that mirrors the dashboard KPIs administrators expect for that context (counts, totals, active vs. inactive, etc.).

3. **Filters & Permissions**  
   Ensure exports respect current filters/searches and user permissions. Where the UI paginates, fetch the full dataset (server-side) before export.

4. **Large Dataset Handling**  
   For tables expected to exceed ~5k rows, consider offloading export generation to an API route to avoid blocking the UI.

5. **Future Enhancements**  
   - Add audit metadata (generated by, timestamp) in summary.
   - Support CSV in addition to XLSX if required by downstream tooling.
   - Provide bulk “Export All” entry point from dashboard if requested later.
